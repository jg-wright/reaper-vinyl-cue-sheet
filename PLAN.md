# Vinyl Cue Sheet — Plan

A REAPER ReaScript that generates a vinyl cue-sheet PDF (like
[examples/Borehead - 0004 - Cue Sheet.pdf](examples/Borehead%20-%200004%20-%20Cue%20Sheet.pdf))
from project regions/markers, distributed via ReaPack.

## 1. Decisions

| Area | Choice |
| --- | --- |
| Language | Lua (embedded, cross-platform, ReaPack-native) |
| Settings UI | ReaImGui (ReaPack dependency `cfillion/reaimgui`) |
| PDF generation | Generate HTML, shell out to an external converter (wkhtmltopdf / pandoc+wkhtmltopdf / Chrome headless) via `ExecProcess` |
| Side vs track detection | **Ruler lanes** (managed via REAPER's Ruler Lane Manager). Two configurable lanes: one holds *side* regions, one holds *track-title* regions/markers |
| Distribution | ReaPack repository (`index.xml` generated in CI, added by URL) |

## 2. Data model

The script reads the project's regions/markers and classifies each by its **ruler lane**
(`I_LANENUMBER`), resolved from a configurable lane *name*.

```
Sides lane      →  [ Side A (region) ][ Side B (region) ] ...
Tracks lane     →  |Blue |Heft |     |Static |Sour |     ...   (regions or markers)
```

- **Sides**: each region in the *sides* lane defines a side. Display name derived from the
  region name, optionally stripping a configurable prefix convention (`!A`/`!B` or `#A`/`#B` → `Side A`/`Side B`).
- **Tracks**: each region/marker in the *tracks* lane whose start falls within a side's
  `[D_STARTPOS, D_ENDPOS)` belongs to that side.
- **Per-track times** (reset to `00:00:00` at each side start):
  - `Start` = track.start − side.start
  - `End`   = nextTrack.start − side.start (or side.end − side.start for the last track)
  - `Length`= End − Start
- **Timecode format**: configurable via `format_timestr_pos(t, "", mode)`. **Default: frames**
  (`h:m:s:f`, mode 5); other modes (m:s, seconds) selectable in settings.

### Classification notes
- Primary: ruler lane by name → lane number (`RULER_LANE_NAME:X` / `RULER_LANE_COUNT`),
  then filter by `I_LANENUMBER`.
- Optional secondary filter: prefix convention for sides, so a lane can be shared if desired.

## 3. Auto-generated content

| PDF field | Source | API |
| --- | --- | --- |
| Title | `$project - Cue Sheet` | `ResolveWildcards(0,-1,"$project",…)` |
| Artist | `$author` | `ResolveWildcards`/`PROJECT_AUTHOR` |
| Album | `$title` | `ResolveWildcards`/`PROJECT_TITLE` |
| Audio Format | render info, e.g. `WAV 48000Hz / 24-bit PCM` | `RENDER_SRATE`, `RENDER_CHANNELS`, `RENDER_FORMAT` (base64 — parse bit depth) |
| Per-side render filename | **standalone configurable pattern** with wildcard tokens (resolved per side) | `ResolveWildcards` per region |

## 4. Global configuration (persistent)

Stored via `SetExtState/GetExtState(section, key, val, persist=true)`, edited in a ReaImGui panel:

- Pre-Master, Engineer, Phone, Email, Client
- Sides lane name, Tracks lane name
- Side prefix convention (e.g. `!`, `#`) and side-name template (`Side %s`)
- Timecode format mode
- Audio-format override (used if auto-detect fails)
- Render-filename pattern (wildcard tokens)
- Output directory + open-after-export toggle
- PDF converter command template (path + args), auto-detected if possible

## 5. Components

```
Vinyl Cue Sheet/
  vinyl_cue_sheet.lua        -- main action: read project → build model → HTML → PDF
  vinyl_cue_sheet_settings.lua -- ReaImGui settings panel (separate action)
  lib/
    config.lua               -- ExtState get/set, defaults, schema
    project.lua              -- metadata + render info (wildcards, RENDER_*)
    regions.lua              -- enumerate regions/markers, classify by lane, build sides/tracks
    timecode.lua             -- format_timestr wrappers
    html.lua                 -- render the cue sheet HTML (mirrors example styling)
    pdf.lua                  -- locate converter, ExecProcess, error handling
    render_format.lua        -- decode RENDER_FORMAT base64 → "WAV 48000Hz / 24-bit PCM"
```

Two actions registered: **Generate Vinyl Cue Sheet** and **Vinyl Cue Sheet: Settings**.

## 6. PDF pipeline

1. Build model + resolve metadata/render info.
2. Render HTML (Arial, thin-bordered tables — matches example).
3. Write HTML to a temp/output path.
4. Convert to PDF via `ExecProcess`, trying detected converters in order:
   `wkhtmltopdf` → `pandoc` (with wkhtmltopdf) → headless Chrome/Edge `--print-to-pdf`.
5. If no converter found: keep the HTML, open it in the browser, and tell the user how to
   "Save as PDF" (graceful fallback).
6. Optionally open the resulting PDF.

## 7. ReaPack packaging

- Package metadata headers in each script: `@description`, `@version`, `@author`, `@about`,
  `@changelog`, `@provides` (list lib files), `@link`, and `@dependencies`/ReaImGui note.
- `index.xml` generated by [`reapack-index`](https://github.com/cfillion/reapack-index) in
  **GitHub Actions** on push to `main`, committed back (or published to a `gh-pages`/release).
- Users install by adding the repo's raw `index.xml` URL in ReaPack → Manage repositories.
- ReaImGui is declared so ReaPack offers to install it.

> Memory note (ci.md): if CI commits `index.xml` to a protected branch, ensure the release
> actor can push (avoid the semantic-release/@semantic-release/git branch-protection pitfall).

## 8. Milestones

1. **Scaffold**: repo layout, `lib/` stubs, one script that prints project metadata to console.
2. **Model**: enumerate regions/markers, lane classification, sides/tracks with timecodes.
3. **Render info**: sample rate + channels + bit-depth decode.
4. **HTML**: pixel-match the example layout.
5. **PDF**: converter detection + `ExecProcess`; HTML/browser fallback.
6. **Settings UI**: ReaImGui panel + ExtState persistence.
7. **ReaPack**: metadata headers, `reapack-index` CI, README install instructions.
8. **Polish**: error messages, edge cases (no sides, empty lane, missing metadata), README.

## 9. Resolved decisions

- **Timecode default**: frames (`h:m:s:f`, `format_timestr_pos` mode 5); other modes selectable.
- **Render filename**: standalone configurable wildcard pattern (not derived from the render matrix).
- **Minimum REAPER version**: v7+ (ruler-lane API).
